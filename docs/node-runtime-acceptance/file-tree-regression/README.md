The existing three-boot persistent file-tree QEMU suite passed: durable hard links, symlinks, recursive removal, GC pressure, cold recovery and independent powered-off image verification. This uses the default 128 MiB IMAC profile with file-tree enabled. It is a regression check of the shared kernel/linker changes, not native Node filesystem acceptance. Kernel hash, runner output, all boot logs and image-verifier results are retained.

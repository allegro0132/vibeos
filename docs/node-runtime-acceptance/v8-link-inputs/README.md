The link checker now records SHA-256 for each archive and every external member of thin archives, compares them again after linking, and freezes the successful ELF into its evidence directory. `python3 scripts/test-v8-link-inputs.py` verifies that mutating a thin member changes the manifest even when the archive index is unchanged; regular archives remain self-contained; missing thin members fail. This validates evidence collection only, not V8 execution. The expected GNU ar error in test.log is the missing-member rejection case.
